# Skolify Website

## Project Overview

Skolify is a website designed to help matric learners prepare for their university journey. The website provides information about universities, courses, applications and funding opportunities in one place.

## Website Pages

* **Home** (`index.html`) – Introduces Skolify and provides navigation to the main sections.
* **About Us** (`about.html`) – Explains Skolify's purpose, mission, vision and the learners it aims to help.
* **Universities & Courses** (`services.html`) – Provides information about universities, courses, applications and funding.
* **Enquiry** (`enquiry.html`) – Allows learners to submit questions about universities, courses and applications.
* **Contact** (`contact.html`) – Provides contact information, a contact form and location information.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Website Structure

The website uses a consistent header, navigation menu, main content area and footer across the pages. The five pages are connected through the navigation menu.

## Main Features

* Five interconnected web pages
* Navigation menu
* University and course information
* Application and funding information
* Enquiry form
* Contact form
* Location information
* Responsive page structure

## Testing

All five pages were tested in the browser. The navigation links were checked to confirm that users can move between the Home, About Us, Universities & Courses, Enquiry and Contact pages.

## Project Purpose

The purpose of Skolify is to make university information easier for matric learners to find and understand while supporting them through their university application journey.
