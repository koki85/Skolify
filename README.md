# Skolify Website

## Project Overview

Skolify is an educational support website designed to help Grade 12 learners prepare for university.

The website provides simple information about universities, courses, university applications and student funding. Parents and guardians can also use the website to support learners with their study choices.

## Target Audience

The main target audience is Grade 12 learners who are preparing to finish school and continue their studies. Parents and guardians are also secondary users.

## Website Purpose

The purpose of Skolify is to make the university application process easier for learners by bringing useful information together in one simple website.

## Website Pages

The website contains five main pages:

- Home
- About Us
- Universities & Courses
- Enquiry
- Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
